# 🏢 电梯停靠 - Elevator Stop

> 一个像素风 H5 小游戏。电梯从1楼匀速上升，在目标楼层精准停下！

## 🎮 怎么玩

1. 注册 6 位数字账号
2. 每局消耗 10 金币（注册送 10 金币试玩）
3. 电梯从 1 楼出发，目标楼层随机 3-18 楼
4. **点击屏幕**让电梯停下，停得越准分数越高！

## ⭐ 得分规则

| 精度 | 奖励 | 说明 |
|------|------|------|
| 🎯 完美对齐 | +50 金币 | 停在目标格正中心 |
| 📍 差 1 格 | +20 金币 | 偏了 1/5 层 |
| 📍 差 2 格 | +5 金币 | 偏了 2/5 层 |
| 💥 差 3 格+ | 失败 | 再接再厉 |

> 每层楼包含 5 格精度单位

## 🔥 连击称号

## 🚀 部署

### GitHub Pages
1. Fork 或上传本项目到 GitHub
2. Settings → Pages → Source 选择 `main` 分支
3. 保存后获得 `https://你的用户名.github.io/仓库名` 链接
4. 用 [二维码生成器](https://cli.im) 把链接转成二维码
5. 手机扫码即可打开游玩！

### 本地运行
直接用浏览器打开 `index.html` 即可，无需服务器。

## 📱 技术

- 纯 HTML/CSS/JS，单文件，零依赖
- Canvas 像素风渲染
- localStorage 本地存储账户数据
- 移动端触屏优化
- 响应式设计（最大宽度 420px）
